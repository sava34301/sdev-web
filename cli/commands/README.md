# `cli/commands/`

Modular command handlers for the `sdev` CLI: running/compiling/native builds (`run.ts`), Personal SDEV dialects & libraries (`dialect.ts`), code understander & local AI configuration (`agent.ts`), cloud authentication & workspace sync (`cloud.ts`), and diagnostics/projects/WASI export (`tools.ts`).
