# `lang/stdlib/ml/`

Pure-SDEV Machine Learning & LLM standard library: N-dimensional tensors (`tensor.sdev`), reverse-mode autograd (`autograd.sdev`), neural layers & batched forward passes (`nn.sdev`), GPT/Transformer models (`transformer.sdev`), training loops & `SDEVML01` binary checkpoints (`train.sdev`), tokenizers (`data.sdev`), CUDA acceleration (`cuda.sdev`), and gated self-evolution (`self_modify.sdev`, `auto_evolve.sdev`).
