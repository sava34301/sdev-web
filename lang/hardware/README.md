# `lang/hardware/`

Pure-SDEV microcontroller support: 30-board database (`board_db.sdev`), Arduino API catalogue (`arduino_api.sdev`), `board` block stripper (`strip.sdev`), natural-language hardware reader (`understand.sdev`), `.ino` C++ transpiler (`transpile.sdev`), virtual breadboard simulator (`simulator.sdev`), and STK500/UF2/Intel HEX protocol engine (`serial_cloud.sdev`).
