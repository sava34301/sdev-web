# `src/hooks/`

Custom React hooks for authentication (`useAuth`), cloud file storage (`useCloudFiles`), debounced workspace sync (`useWorkspaceSync`), Personal SDEV dialects (`useDialects`), hybrid translation (`useCodeTranslation`), clipboard copying (`useClipboard`), user handles (`useUsername`), and admin checks (`useIsAdmin`).
