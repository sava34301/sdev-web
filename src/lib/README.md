# `src/lib/`

General frontend utility modules: protocol-aware router selector (`app-router.ts`), file download helpers (`download.ts`), typed `localStorage` JSON helpers (`storage.ts`), launch gate & countdown helpers, Google Calendar link builder, Tailwind class merger (`utils.ts`), and MCP server definitions.
