# `src/lang/stdlib/`

Domain standard library modules bound into the interpreter: 2D Canvas & Turtle graphics (`graphics.ts`), virtual OS kernel (`kernel.ts`), linear algebra & matrices (`matrix.ts`), Python parity builtins (`pyparity.ts`), declarative UI widgets (`ui.ts`), and full-stack HTML5/CSS3/JS Website Building Toolkit (`web.ts`).
