# `src/lang/core/`

Foundational SDEV language layer with zero upward dependencies: token definitions (`tokens.ts`), keyword tables (`keywords.ts`), lexer (`lexer.ts`), AST node types (`ast.ts`), recursive-descent parser (`parser.ts`), lexical environment (`environment.ts`), runtime value types (`runtime-values.ts`), formatting (`format.ts`), and error classes (`errors.ts`).
