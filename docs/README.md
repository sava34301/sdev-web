# SDEV Documentation Hub

Welcome to the canonical documentation index for the **SDEV Programming Language** (v1 Classic, v2 "Prism", `sdev:ai`, and Personal Dialects).

Every guide lives here once under a categorized, structured path and is served directly inside the [Web Documentation Viewer](/docs) and compiled into the [Ultimate Reference Compendium](01-overview/ultimate-reference.md).
