# `public/firmware/`

Pre-compiled ESP32 family bootloader and partition table binaries used by the in-browser ESP32 Web Serial SLIP flasher.

<!-- FOLDER_INVENTORY_START -->
## Folder Contents

### Subfolders

| Subfolder | Purpose |
| :--- | :--- |
| [`esp32/`](./esp32/) | Bootloader (`bootloader_dio_80m.bin`), OTA data (`boot_app0.bin`), and partition table (`partitions.bin`) for classic ESP32 boards. |
| [`esp32c3/`](./esp32c3/) | Bootloader, boot app, and partition binaries for ESP32-C3 (RISC-V) boards. |
| [`esp32s2/`](./esp32s2/) | Bootloader, boot app, and partition binaries for ESP32-S2 boards. |
