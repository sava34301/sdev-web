# `public/`

Static web assets served at the root URL, including standalone JS/Python/compiler bundles, downloadable books (PDF), Arduino library index, ESP32 bootloader firmware, sample programs, and the WebAssembly Seed VM.

<!-- FOLDER_INVENTORY_START -->
## Folder Contents

### Subfolders

| Subfolder | Purpose |
| :--- | :--- |
| [`arduino/`](./arduino/) | Pre-built compact JSON index (`library-index.json`) of 10,232 official Arduino Library Manager libraries for instant browser search and header resolution. |
| [`downloads/`](./downloads/) | Release artifacts generated by `node scripts/release.mjs`: the VS Code extension (`sdev-language.vsix`), standalone CLI bundle (`sdev.mjs`), WebAssembly Seed VM (`sdev-seed.wasm`), and x86-64 native runtime (`runtime.s`). |
| [`firmware/`](./firmware/) | Pre-compiled ESP32 family bootloader and partition table binaries used by the in-browser ESP32 Web Serial SLIP flasher. |
| [`samples/`](./samples/) | Bundled sample `.sdev` programs (`quiz.ai.sdev`, `todo.ai.sdev`, `welcome.v2.sdev`) loadable from the Web IDE. |
| [`wasm/`](./wasm/) | Compiled 32-bit WebAssembly Seed VM binary (`sdev-seed.wasm`, built from `src/lang-bridge/seed/seed.wat`). |
