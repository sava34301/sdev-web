4. **Essential distribution unlocks adoption:** Does not survive as scoped. Multi-platform Electron distribution is premature and futile without users, especially after the defense conceded that purchasing the code signing certificate required for clean Windows distribution is financially indefensible.

**The Single Issue for the Jury:**
The jury must decide whether a solo, self-funded student developer can execute an unprioritized five-domain roadmap all at once, or whether attempting everything simultaneously guarantees burnout and toolchain collapse before gaining any users.
